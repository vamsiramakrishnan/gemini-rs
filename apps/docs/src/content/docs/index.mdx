## Choose the application you want to build

| Goal | Start here | Check before expanding |
|---|---|---|
| A text agent | [Text agents](/gemini-rs/compose/text-agents/) | One request, tool result and returned answer |
| A voice conversation | [Live sessions](/gemini-rs/live/live-sessions/) | Connection, audio output and interruption handling |
| A constrained tool workflow | [Governed flows](/gemini-rs/compose/flow/) | Allowed transitions and denied actions |
| A conversation test suite | [Conversation CI](/gemini-rs/compose/conversation-ci/) | Scripted scenarios, independent of model calls |
| A custom transport | [Architecture](/gemini-rs/start/architecture/) | Wire events and the layer you need to replace |

The fluent crate supplies application builders. The runtime owns state,
callbacks and tool dispatch. The wire crate owns protocol and transport.
The independent [memory crate](/gemini-rs/memory/memory/) adds session memory.

A declared flow can constrain tool dispatch. Its instruction text does not
make every model utterance correct. Test control-plane behavior offline, then
measure the live model and transport separately.

## Connect a voice session

```rust
use gemini_adk_fluent_rs::prelude::*;

Live::builder()
    .instruction("You are a helpful concierge.")
    .greeting("Greet the caller.")
    .connect_from_env().await?     // Google AI or Vertex — resolved from env
    .talk().await?;                // microphone in, speakers out, barge-in handled
```

Or with explicit callbacks:

```rust
use gemini_adk_fluent_rs::prelude::*;

let handle = Live::builder()
    .voice(Voice::Kore)
    .instruction("You are a helpful voice assistant.")
    .on_audio(|pcm| { /* play audio */ })
    .on_text(|text| print!("{text}"))
    .connect_from_env()
    .await?;

handle.send_text("What's the weather like?").await?;
handle.disconnect().await?;
```

## Edit and test a session specification

A whole governed session — flow DAG, tools, extraction, phases, watchers,
computed state, memory, runtime tuning, and an embedded test suite — can be one
JSON document (`SessionSpec`). It validates, simulates, and code-generates
offline, and the [Flow Studio](/gemini-rs/compose/flow-studio/) is a
drag-and-drop editor over exactly that document:

<p align="center"><img src="/gemini-rs/assets/studio/flow-studio.gif" alt="Flow Studio click-through: load a cookbook, drag nodes, validate, run embedded tests, scrub a simulated session, read the generated Rust" width="860" /></p>

See [Flows as JSON](/gemini-rs/compose/flow-json/) for the format and
[the Studio tour](/gemini-rs/compose/flow-studio/) for the editor.
