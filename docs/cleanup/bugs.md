# Bug bash log

Each bug found in Phase 3 with its cause, fix and the regression test that
fails before the fix.

| # | Area | Symptom | Cause | Fix (commit) | Regression test |
|---|---|---|---|---|---|
| 1 | Telephony G.711 | The encoders matched no reference: against ITU-T G.191's `g711.c` (the STL reference implementation) the µ-law encoder disagreed at 127 inputs and a first rewrite in the Sun `g711.c` form at 508 (Sun negates a negative sample, G.191 takes its one's complement, so they differ by one code at negative step boundaries); A-law was already G.191-exact | The old encoders took the magnitude of the 16-bit sample and truncated toward zero instead of converting to the 14-bit (µ) / 13-bit (A) domain with an arithmetic shift and complementing negatives | µ-law encoder rewritten as G.191's `ulaw_compress` (`telephony/g711.rs`); the reference test module transcribes G.191's four functions from the ITU source and anchors them with literal G.711 table pairs and a decode→encode round trip, so a transcription error shared with the implementation cannot pass | `telephony::g711::reference_tests::*` (encoders and decoders vs G.191 for every input; round trip; known pairs), `tests::ulaw_negative_values_mirror_the_reference` |
| 2 | CLI | `adk flow inspect /missing.json` (and `flow graph`, `flow validate`, `flow ci`, `flow simulate`, `replay`, `session scenario`, `eval`) printed `Error: Os { code: 2, kind: NotFound, ... }` without the path; `spec *` and `bundle push` named it | Bare `?` on `fs::read_to_string` in `commands/{flow,replay,session,eval}.rs` | Every read names its path in the error | `cli_help::flow_session_and_replay_commands_name_a_missing_file` |
| 3 | SessionSpec / Flow Studio | A document with `"runtime": {"temperature": 0.6}` saved through Studio came back as `0.6000000238418579` | `RuntimeSpec.temperature` is `f32`; serde widens it to `f64` for JSON, printing the exact binary value | `serialize_with = "serialize_f32_exact"`: the shortest round-tripping decimal of the `f32` | `studio_round_trip` (the allow-list entry for `runtime.temperature` is removed once the fix lands) |
| 4 | Live control lane | A user barge-in that cancelled an in-flight inline tool emitted `LiveEvent::ToolCancelled` but never ran the application's `on_tool_cancelled` hook; only a server `toolCallCancellation` did | `tool_handler.rs` sent the event and skipped the callback dispatch the server path performs | The hook runs for local cancellations too, in its configured execution mode; the callback doc says so | `session_lifecycle::a_barge_in_during_an_inline_tool_cancels_it_without_a_response` |
| 5 | SessionSpec codegen | `SessionSpec::to_rust` on a `conversation` document (every Flow Studio gallery example) generated a program with no governance at all: the conversation was dropped and no flow chain emitted | `to_rust` embedded the document only for skills documents and otherwise rendered `self.flow`, which a conversation document does not set | A conversation document takes the same path as a skills document: the generated program carries the document and calls `spec.apply(...)` | `spec_round_trip_props::gallery_documents_generate_their_own_flow` |
| 6 | SessionSpec codegen | A document whose `description` had a line break generated a `main.rs` that did not parse: the second line fell outside the `//!` comment | `to_rust` wrote the whole description after one `//! ` | One `//!` per line | `spec::codegen::tests::a_multi_line_description_stays_inside_the_doc_comment`; found by `spec_round_trip_props::generated_rust_parses_and_declares_the_same_flow` |
| 7 | Telemetry lane (loom) | With two concurrent `record` calls, a reader could compute a latency percentile over a ring slot that was claimed but not yet written (a `0` sample), so `p50` fell below `min` | `stats()` sized the recent window by `count` and assumed `count` and the ring index advance together; with two writers the slot order and the publication order differ | Ring slots hold `latency + 1` and are published individually; `stats()` reads every claimed slot and skips the unwritten ones | `live::telemetry::loom_tests::loom_two_writers_one_reader_count_never_exceeds_visible_samples` (loom, every interleaving) |
